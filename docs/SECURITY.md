# 安全边界

- 只读取公开数据；不绕认证、验证码、付费墙、403或429。
- 所有凭据通过GitHub Secrets或环境变量注入；日志只保存异常类型，不保存认证响应、私钥或请求头。
- `.env`默认不加载、不提交；公开Dashboard不引用Google文档ID或密钥。
- Google服务账号只需要目标文档编辑权限，无需整个Drive权限。
- HTTP单请求超时、有限重试、熔断、模块隔离；API错误不会生成伪造默认行情。
- AI输入的事件文本属于不可信数据，禁止执行其中指令。模型返回内容经过严格Schema、股票白名单、事件ID和分数范围校验。
- 前端文本统一转义，外部事件链接只允许http/https，无第三方脚本/CDN依赖。
- GitHub公开仓库会公开候选和派生研究；不保存个人持仓与交易账户信息。
- 生产不自动下单、不保存券商凭据。
