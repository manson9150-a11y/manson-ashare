# 个股研究改版 · 2026-09-12

MANSON 聚焦个股的持续研究。市场全景、连板天梯与题材榜链接到悟道，本站不再重复排列市场榜单。悟道仍在每个正式阶段按现有配额规则调用，供研究背景使用。

## 每次输出

- 短期强势：量价与趋势判断、条件观察区间、确认条件、失效参考。
- 独立催化：已核验的公司事实、可能影响的经营环节与下一步兑现条件。
- 高波动观察：短期快速上涨或高波动个股；不预测“成妖”，默认没有入场区间，也不纳入入场候选收益统计。其独立催化标签同时可通过催化筛选查到。
- 跟踪变化：与前序快照比较，保留暂停原因；前次失效参考被当前快照跌破后，停止生成新入场区间，不能简单向下重画条件。

08:00 / 12:00 / 22:00 三阶段不变。B/C/H 分别最多12/5/8只，A保留空键兼容旧格式。次日晚间以外仍优先追踪前序名单；盘前允许新发现的已核验独立事件。高波动名单同样保留行情、因子和K线，以便隔夜及午间延续。

## 发现范围

晚间历史预算不再由板块映射硬限制。首先保留已核验事件及前次个股，再轮流分配给当日涨幅、正涨幅高成交额、正涨幅高换手和板块线索，最多250只。前端明确区分全行情数量和历史样本数量。未映射板块不再直接否决个股，但历史不足、ST、退市标志、停牌、成交额不足及已知硬风险仍需排除。

热度阈值为5日涨幅20%、20日涨幅40%或NATR 7%，同时要求价格在MA20上方、5日正涨幅。普通短期强势需符合现有位置规则，5/20日涨幅为正且价格高于MA20。排序只用于研究优先顺序，不表示成功概率。

## 价格计划口径

MA10 ± 0.2 ATR14 为回踩观察区，MA10 − 0.8 ATR14 为失效参考；四舍五入后必须严格满足失效价 < 区间下沿 < 上沿。至少61根有效历史、对应行情日期及可比成交额条件满足时才给区间。高波动、硬风险、历史不足和午间无同时间成交额基线均不发布入场区间。

20根已观察日线最高价只作阻力参考，不是目标价。仅阻力高于区间上沿才计算空间/风险距离；不足1.5时标为继续等待。涨停或距离区间较远会额外标注等待成交条件/不追价。未经复权、公司行动未完整核验，区间不是实时委托、不保证可成交，也不用于回测成交收益。

## 公告分析

不把公告标题当作结论。卡片先给研究判断、业务影响和下一步验证，原文在折叠依据内。自动卡片明确标为证据规则分析；当前付费语言模型增强没有启用。

正文核验 v2 优先识别合同调减，不因剩余金额大就作为新增正向催化。一般“解除条款”不等于已经解除合同。未解析成功仅表示结构化证据不足，不能断言合同没签。业绩说明会和例行治理文件不当作盈利增长事实。

另有4家公司官方PDF逐份实读分析，保存于 `dashboard/data/catalyst_reviews.json`。围海股份合同调减；通光线缆同项目中标金额恢复原预期；汉缆股份等待中标书面确认/合同；美腾科技披露销售签约但规模重要性未核定。每条保留来源与阅读时间，这些是9月12日补充分析，不冒充9月11日原任务的判断。将来不同原任务只放入“历史实读分析”。
