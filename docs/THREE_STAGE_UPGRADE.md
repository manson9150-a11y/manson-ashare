# 三次调度与因子能力升级 · 2026-09-10

每日交易日只运行08:00盘前计划、12:00午间验证、22:00晚间完整复盘。晚上独立扫描，次日继续验证。调度时间是目标启动时刻，实际开始/完成和行情日期分别记录。旧五阶段结果、收益记录和Google文档内容保持冻结。

## 为什么旧页面显示很多不可计算

旧市场模块固定列出11项，主流程再固定追加5项，并非16个接口同时故障。供应商连板层级和板块主力净额已有局部记录，旧文案仍显示缺失。另一些指标确实需要连续历史，或尚未实现完整模型。

能力表改为可用、部分可用、暂无有效数据、未接入模型/评分、需人工核验，逐项记录原因、覆盖范围、来源、时点和是否参与评分。市场规则分仍只使用广度，不把新指标未经验证地塞进分数。

## 本轮计算与展示

- 新浪成交额日线、BaoStock独立备用日线；腾讯仅有价格时继续换源。缓存可增量更新，但不跨缺失交易日。
- 三大指数5/10/20日涨幅与均线位置；午间使用明确注明日期的前收盘趋势。
- 东方财富涨停池与炸板池同口径的炸板率；不以开板次数求和充当炸板股票数。源不可用时只展示有明确涨停价的局部样本。
- 前交易日归档涨停群组的当日等权涨幅、1进2/2进3/3进4晋级、至少3板群组下跌占比。缺前序、缺成分行情、无分母时保留缺口。
- 全市场成交额基线按连续完整收盘累计，满5/10/20日才提供对应窗口；午间不与全日总额比较。
- 候选表显示首板/已连板、规则分与计分覆盖；详情保留5/10/20日价格和成交额因子；MA数字适当舍入。
- 取消把规则分复制成交易性分。技术风险与事件核验状态分别标注。C池逐项记录未入选原因。
- 板块“持续强势”要求多日覆盖达标和连续上涨证据；仅有当日广度时显示“当日强势”。历史状态在页面作解释，不改写旧JSON。
- 手机导航保留、筛选条件和数据源可读；因子按项展开，避免嵌套长滚动区。

## 仍需积累或独立核验

全市场20日同口径成交额历史、全市场涨跌停价、所有板块成员历史均不可由250只历史预算推断。短线情绪周期、外部市场评分、龙虎榜席位归因、完整公司行动及消息因果验证尚未完成；不填0也不假装已可用。免费源的可用性和更新时间每次重新检查，遇到访问或额度限制正常降级。

## 收益观察口径

版本2盘前观察从前收盘至信号当日收盘，午间从上午收盘至当日收盘，晚间从当日收盘至下交易日收盘。午间信号不使用此前当日上午的开盘/高低价作为后续表现。记录观察条数、独立交易日、窗口和定义；旧口径分组保留。这是价格观察，不是含成交约束和费用的可执行策略收益。

## 验证

`pytest -q` 验证阶段链、周末迁移、午间时间戳、历史缓存、跨日群组、量价回退及收益时点；`node --test tests/test_dashboard*.cjs` 验证页面展示适配。`python -m src.cli --demo --stage full_pipeline --date 2026-09-04` 离线跑完前日晚间与当日三次链。`python -m src.verify_free_data` 只读校验多个免费上游并留下产物。线上UI、数据日期和发布版本需另行验收，不能以测试通过代替。

本地验收：164项Python测试与14项前端适配测试；四段离线链全部COMPLETE。9月10日只读实测四个上游均有当日日线，其中东财、新浪和BaoStock成交额一致（舍入误差内）。使用已冻结的5,548只当日收盘行情测试市场增强：三大指数成功，前日48只涨停名单行情全部匹配；当前供应商涨停/炸板接口超时或不完整时，晋级率与炸板率保持不可用。验收产物在本地artifacts目录，不混入正式阶段。
