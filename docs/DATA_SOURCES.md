## 公告处理

巨潮使用公开股票目录与 `https://www.cninfo.com.cn/new/hisAnnouncement/query`。按候选股票逐只查询最近7天，完整读取最多3页，每页30条；股票映射缺失、分页截断、异常响应都视为采集失败，不能假装查无公告。请求间隔、超时、重试沿用来源配置；遇到401/403/429不绕过限制、不立即重试。错误日志现在同时保存HTTP状态码，不保存敏感响应内容。

优先巨潮，失败后切换东方财富。两个来源都失败则保留已知事件并提示缺口。公告标题与原始链接、代码、来源、时间精度都保留；只读到标题时不标记正文已核验，不据此确认独立催化。历史公告风险核验仍不完整。

日期为午夜的巨潮记录保守标记为“仅日期”。当天记录只有在研究截点前已被系统观察才可纳入，首次观察时间另存于 `data/latest/announcement_first_seen.json`；前一日期的记录可按日期边界使用。精确发布时间和首次观察时间不会相互冒充。跨来源同股票、同日期、同类型和同标题记录去重。

本次成功数据已用于刷新周末初始化，9月4日历史复盘保持原有历史口径。云端可从 Actions 的 **Verify free announcement sources** 手动检查来源，产物保存查询结果和日志；这个检查不会写入正式行情、候选名单或Google文档。

## 悟道 MCP（2026-09-07 接入）

稳定入口 `https://stock.quicktiny.cn/api/mcp`，只用 Streamable HTTP POST / JSON，无独立 GET SSE 连接。密钥仅从 `WUDAO_API_KEY` 环境变量读取；GitHub Actions 使用同名 Secret，浏览器不请求认证接口。

每个有效的新正式阶段（08:00、12:00、22:00）都请求一次题材强度榜和一次行业涨幅榜，最多读取前十题材成分，总计最多 12 次业务工具调用/阶段、36 次/完整交易日（不含协议握手及人工验证）。服务实际额度未假定；401/403/429 或明确额度错误停止本次后续调用，记录缺口，保留原接口备用。不自动重试、购买套餐或调用任何 watchlist 工具。休市、越窗、前序缺失和已完成阶段读取不发起新研究请求。

日期按实际行情基准：08:00请求前一交易日，午盘/收盘/晚间请求当日。要求 tradeDate 与 actualTradeDate 一致、快照时区明确且不晚于研究截点；12:00阶段须为当日11:30及之后、且不晚于本次截点的快照；旧11:35阶段仍保留原20分钟检查。仅观察到当前版本的题材成分，拒绝未来、超过7日、无时间或截断的成分；模糊匹配使用返回的真实分类名，保留请求名，不假装一对一对应。

22:00 将有效题材成分补入原行业映射，用完整行情重算原有板块规则分，并参与历史日线筛选范围；12:00 同样补充映射但仅验证早盘候选。08:00保留正式前序的行情/因子/规则分，刷新悟道热点和候选题材标签，不重新海选。热点原始强度单独展示，不转换成未经校准的0–100分，不作为独立催化或风险核验依据。旧公告接口仍负责公告风险。

新报告和 Google Docs 包含悟道快照及采集状态。`Verify Wudao Research` 是独立的手工云端验收，可发布有实际观察时间的首页热点补充，不回写历史阶段候选与报告。历史复盘链接不读取补充数据。

## 2026-09-10 免费日线扩展

|渠道|已接入能力|实测与限制|
|---|---|---|
|东方财富|股票 / 指数日线、成交额、涨停池和炸板池|请求交易日、代码与返回数量检查；空池不自动视为零。|
|腾讯|股票 / 指数日线、实时明确涨跌停价|日线没有成交额时继续尝试其他来源，不以收盘价乘成交量代替。|
|新浪|新增未复权日线含真实成交额、三大指数日线|仅提取编码数据，用仓库内固定MIT解码器处理；不执行接口返回的JavaScript。|
|BaoStock|新增独立免费股票 / 指数日线备用|匿名SDK，无账户密钥；独立子进程串行调用、25秒硬超时。北京市场暂不走此渠道。|

本机只读交叉核验：600000在2026-09-10收盘价9.35元；东财和新浪成交额555,882,181元，BaoStock为555,882,180.54元（舍入差异），腾讯无该字段。此为单标的核验，不能推断全市场接口永远可用。BaoStock行业目录探测超时，未把它作为有效行业映射发布。

历史缓存每只保留100根，数据时点不晚于研究截点；缺当天、少于61根、异常跳变或与现价冲突时依次换源。已有完整连续前收盘序列可由当日已验证收盘行情增量更新；缺交易日不能直接跨过。市场成交额基线另按至少98%行情覆盖的连续完整交易日积累。

运行 `python -m src.verify_free_data` 可生成 `artifacts/free_sources.json`；云端 **Verify free daily data sources** 独立验证连通性及成交额交叉一致性，不写正式报告或Google文档。AKShare属于接口封装，本项目借用其开源解码器，并不把AKShare重复算作另一个独立上游。
